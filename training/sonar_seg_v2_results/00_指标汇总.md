# sonar_seg_v2 — 声呐图像 3 类分割结果

- 数据集：`D:\sonar_database_v2`（Roboflow v2 导出，zip 已解压）
- 类别：`box_crate`（箱体）/ `pipe`（水管）/ `shipwreck`（沉船），背景为隐含负类
- 图片：train 836 / valid 192 / test 91（其中纯背景图 79 / 7 / 6）
- 实例：train 189 箱体、207 水管、1213 沉船

## 训练

| 项目 | 值 |
|---|---|
| 模型 | yolov8n-seg（预训练） |
| 输入 / batch | 512 / 16 |
| 设备 | RTX 4060 Laptop 8 GB（GPU 0） |
| epochs | 194 / 1000（早停，best = epoch 84） |
| 单 epoch | 15 秒（GPU 实际耗时） |
| 实际训练时长 | 48.6 分钟（总耗时 2.85 小时，其中约 2 小时是系统睡眠把进程挂起） |
