## 推理

```python
from ultralytics import YOLO

model = YOLO("best.pt")
results = model("your_image.jpg", imgsz=512, conf=0.5, device=0)

for r in results:
    for box, cls, conf in zip(r.boxes.xyxy, r.boxes.cls, r.boxes.conf):
        print(model.names[int(cls)], float(conf), box.tolist())
    r.show()          # 或 r.save("out.jpg")
```

掩膜在 `r.masks.data`（形状 N×H×W，已归一化到原图尺寸时用 `r.masks.xy` 取多边形）。
